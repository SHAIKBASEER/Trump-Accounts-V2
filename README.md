# Trump Accounts Monitor Dashboard

Compact, GitHub-ready source for the Living Cities dashboard, including the enhanced **Four supporters. One child?s future.** 1080p video.

## Run locally

1. Install Node.js 22.13 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://127.0.0.1:5173/`.

## Included

- Full dashboard, program monitor, and opportunity planner source
- Final public data used by the application
- Three final 1080p narrated story videos and captions
- Build, database migration, and deployment configuration

Generated dependencies, caches, render intermediates, data-generation utilities, unused UI components, and older video revisions are intentionally omitted.
